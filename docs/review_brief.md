> 다른 AI/연구자에게 그대로 붙여 넣어 비판적 검토를 받기 위한 자기완결형 정리다. **1차 검토(GPT)의 지적과 우리 대응, 그 뒤 새로 나온 결과**를 반영했다. 숫자는 모두 실제 로그에서 뽑았고, seed 수·중간값·미완료를 표시했다. 좋은 점보다 **약점·겹치는 선행 연구·위험**을 찾아 달라는 것이 목적이다.

## 0. 1차 검토 요약과 이번에 묻고 싶은 것
- **1차 판정(GPT)**: 지금 제출이면 Weak Reject, ICML 2027 목표로 9주 더 쓸 만함. 가장 큰 약점은 "FedAPEN의 공유 모델은 학습 중 private의 KL·앙상블 손실로 도움을 받았으므로, *공유 + 비율 > 앙상블*은 **추론 결합**이 쓸모없다는 것까지만 보이고 **학습 중 지식 전달** 효과는 측정하지 못한다"였다. 그 밖에 scout 단독 행, 기준선에도 같은 하이퍼파라미터 탐색, validation 기반 선택, 이론(C2)의 약함, 두 번째 이중 모델, 실제 도메인(DomainNet), 실기기 실측 보강을 요구했다. 권고: **12월 중순에 (a) 학습 중 전달 분리 대조와 (b) 실제 도메인 결과를 보고 ICML 제출을 판단.**
- 우리는 이 권고를 모두 채택했다(6절 대응표). **이번 검토에서 묻고 싶은 것은 9절.**

## 1. 문제 설정
- **모델 이기종 연합학습(HtFL)**: IoT 기기마다 다른 구조의 모델(private)을 쓴다. 기존 HtFL은 구조가 달라도 통하는 통로로 지식을 나눈다: prototype(FedProto, FedTGP), anchor(FedSA), head/logit(LG-FedAvg, FedGH), 그래프(FedRG), 작은 공유 모델 + private 상호 학습/앙상블(FML, FedKD, FedAPEN, FedMRL, pFedMoE).
- 설정(IoT 가정): 증강 없음, Dirichlet label skew α = 0.1, 클라이언트 20명, 모델 구성 HtFE-img-8(클라이언트 i는 FedAvgCNN/GoogLeNet/MobileNetV2/ResNet18·34·50·101·152 중 i % 8), 500 라운드, 로컬 1 epoch, seed 3개. CIFAR-100, Flowers102, Tiny-ImageNet. 평가는 10라운드마다 개인화 test 정확도. **보고 지표: (1) seed 평균 곡선의 최고값(기존 관행, 모든 방법에 같은 낙관 편향), (2) 마지막 평가 값(선택 없음), (3) 같은 seed·분할에서의 짝지은 차이.**

## 2. 핵심 주장
- **C1 진단**: label skew에서 이기종 private 모델은 "지역 클래스 비율" 이상을 거의 더하지 못한다. 학습 없는 *공유 + 비율*(공유 모델 logit + log 지역 클래스 빈도)이 이중 모델 앙상블과 같거나 낫다. **단, 1차 검토 지적대로 "학습 중 전달"까지 포함하는지는 CE 대조(진행 중)로 판정한다.**
- **C2 이유**: label shift에서는 클라이언트 k의 Bayes 최적 분류기가 `g(x) + log π_k − log π`(명제 1; Saerens 2002, Lipton 2018, Menon 2021의 고전 결과). 공유 모델이 사후확률을 잘 추정하면 어떤 통로도 private이 이를 넘을 수 없다. feature shift에서는 x 의존 보정 r_k(x, y) = p_k(x|y)/p(x|y)가 생겨 private이 기여할 수 있다(명제 2). **새로 추가한 증거: 공유 모델 품질에 따른 궤적(4.4).**
- **C3 설계(FedScout, 2단계)**: 연합은 모든 기기가 같은 구조로 갖는 작은 c8 scout(CIFAR ResNet-8, 8.5만 파라미터)만, 이기종 learner는 연합 뒤 로컬에서만(scout 위 잔차, 확신 없는 샘플만, cascade 추론).
- **C4 효율**: 같은 정확도대에서 기기 학습 시간·에너지가 이중 모델 방법보다 수 배 적다(Pi 5·Jetson Orin Nano 측정).
- **제목**: *Rethinking Knowledge Sharing in Model-Heterogeneous Federated Learning: Share a Tiny Common Model, Specialize Locally*.

## 3. 방법: FedScout 최종 구성 (11-20 확정)
- scout: c8, projector 없음(자기 분류기 64×C), **모델 전체 FedAvg**, scout lr = 0.03(private 0.01 × 3), **head lr ×8**. (탐색으로 정한 하이퍼파라미터. 기준선은 원 논문 lr 0.01 → 공정성 탐색 진행 중, 6절.)
- 1단계 R1–R490: 기기는 scout만 CE로 학습(learner 미학습). 통신 = scout 전체 84.6K floats/라운드(업·다운 각각; FedAPEN 512×C head 129.4K).
- R490: scout 동결, head를 지역 데이터로 개인화.
- 2단계 **로컬 50 epoch(통신 0)**: learner를 scout logit 위 잔차로 학습(`out = learner(x) + scout(x)`), screening(고정 scout가 정답 확률 ≥ 0.5로 맞히는 샘플 제외; learner는 약 30%만 학습).
- 추론: `scout + α·learner`(α는 held-out 5%로 선택), cascade(scout 확신 ≥ τ면 learner 생략).
- 표기: "490R 연합 + 50 로컬 epoch"(기준선 500R와 따로 표시, 연산은 모두 포함). 평가 때 head 1 epoch 미세 조정(개인화 평가).
- 로컬 epoch E 근거(Flowers, seed 3개): E = 10/50/100 → 69.32/69.62/69.52, learner 기여 −0.28/+0.91/+0.81 → 50에서 포화.

### 4.4 언제 private이 이기나 — 공유 모델 품질 궤적 (새 결과)
native head FedAPEN, seed 0, 평가마다(10라운드) 앙상블 − (공유 + 비율)을 공유 모델 단독 정확도에 대해 그렸다(R0 제외).
- **라벨 이동**: 공유 모델이 좋아질수록 private 이득이 단조 감소하다 **0 아래로**. Dir 0.1: 최대 +8.6(R40, 공유 8%) → 공유 약 18%(R430)에서 0 → R500 −1.5. Dir 1.0: +2.1(R20) → 공유 약 15%(R130)에서 0 → −5.3.
- **feature shift(IID + shift)**: 공유 모델 품질과 무관하게 **+3 안팎 유지**.
- 해석: 라벨 이동에서 private의 이득은 공유 모델이 사후확률을 아직 못 맞추는 동안의 일시적 효과(명제 1의 전제가 깨진 구간)이고, feature shift에서는 명제 2의 x 의존 보정 때문에 남는다. 1차 검토에서 지적된 "native head R330 → R500 역전"이 이 궤적의 한 단면이다.

| 데이터 | τ | 정확도 | learner 실행 비율 | Pi 5 지연 | Orin 지연 |
|---|---|---|---|---|---|
| CIFAR | scout만 | 65.55 | 0 | 2.9 ms | 5.0 ms |
| CIFAR | 0.5 | 66.04 | 0.32 | 16.6 ms | 14.1 ms |
| CIFAR | 항상 learner | 66.05 | 1.00 | 45.7 ms | 33.4 ms |
| Flowers | scout만 | 68.71 | 0 | 9.3 ms | 4.9 ms |

| Flowers | 항상 learner | 69.62 | 1.00 | 84.6 ms | 34.3 ms |
- τ = 0.5 cascade는 learner를 항상 실행할 때 지연의 36–42%(2.4–2.8배 빠름)로 정확도는 같거나 높다. scout 단독은 cascade보다 2.8–5.7배 빠르고 정확도는 0.5–1.1점 낮다(Pi CIFAR: 2.9 → 16.6 ms에 +0.49점). 그래서 **scout 단독을 독립적인 배포 선택지로 본 표에 둔다.** 표의 지연은 한 번 잰 배치 1 추론 지연의 조합이며, 실제 cascade 실행의 p50·p95는 아직 재지 않았다.

## 7. 위험과 약점 (갱신)
1. **C1의 범위가 CE 대조에 달림**: CE로만 학습한 공유 모델 + 비율이 FedAPEN 공유 + 비율(61.2)보다 확실히 낮으면, "private은 추론 결합에서는 쓸모없지만 학습 중에는 공유 모델에 지식을 넣는다"로 C1을 좁혀야 한다.
2. **"그냥 c8 FedAvg + 미세 조정"**: scout 단독이 결합과 0.3~0.9점 차이. 방법 노벨티는 얇고, 진단·이론·효율의 묶음으로 승부해야 한다.
3. **하이퍼파라미터 비대칭**: 공정성 탐색 결과에 따라 FedAPEN과의 차이가 크게 줄 수 있다(FedAPEN에 head ×8을 주면 공유 모델이 크게 좋아질 가능성).
4. **이론은 고전 결과의 이식**: 정량적 유한 표본 경계 없음. 대신 궤적(4.4)·표본 수 축·보정 사다리로 실증.
5. **feature shift가 합성**(DomainNet 대기). 합성 변환(회전·반전)은 강한 이동이라 실제 도메인에서 효과가 작을 수 있다.
6. **seed**: 4.3–4.5 대부분 seed 0(seed 3개 진행 중). native head D-대조는 근소 미달, 기본 FedAPEN에서는 중간값으로 통과.
7. **평가 프로토콜**: 최고값 지표의 낙관 편향(마지막 평가를 병기), 일부 기준선은 500R에서 미수렴(FedAPEN 1000R 진행 중).
8. **540R vs 500R 표기**, **실기기 추정치**, **범위**(이미지, label skew 중심, 20명, 지역 데이터 적음), **분야 부정 인상**(label shift에서의 상한이지 이기종 FL 전체의 부정이 아님을 명시).

## 8. 논문 계획 (갱신)
- 투고: ICML 2027(초록 01-14, 본문 01-22 AoE, **본문 8쪽**) → 떨어지면 TMC. 12월 중순에 CE 대조·DomainNet 결과로 제출 여부 판단.
- ICML 구성: 서론(HtFL 통로는 무엇을 전달하나) → 진단(관찰 1, FedAPEN·FML 분해, CE 대조) → 이유(명제 1·2, 예측: τ = 1, α 의존, 공유 품질 궤적, feature shift에서 역전, 표본 수 축, 보정 사다리) → 설계(2단계 FedScout, 진단의 귀결) → 결과(본 표 + scout 단독, 통신·연산·라운드 곡선, 실기기, ablation, 일반화, DomainNet) → 한계.
- TMC 버전: 실기기 실측(실제 연속 라운드, 에너지, 낙오자, cascade 지연) 비중 확대, 이론 축약.
